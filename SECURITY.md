# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Email the maintainer at **gabrielepartiti@icloud.com**
3. Include a description of the vulnerability and steps to reproduce

You should receive a response within 48 hours. Once confirmed, a fix will be released as soon as possible.
